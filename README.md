# Rutuja Dhamal Portfolio

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript.

## Live website

[https://rutuja-dhamal.github.io/portfolio/](https://rutuja-dhamal.github.io/portfolio/)

The site is published from the `main` branch using GitHub Pages. New commits to `main` are deployed automatically; no build command is required.

## Local preview

Open `index.html` in a browser, or serve this folder with Python:

```powershell
py -m http.server 8000
```

Then open `http://localhost:8000`.

> The profile photo and resume in this public repository are accessible to anyone. Do not upload credentials or private files.
